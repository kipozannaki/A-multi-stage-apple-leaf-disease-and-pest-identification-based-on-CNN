# 叶片健康状态分类项目

## 项目简介

本项目是一个基于深度学习的叶片健康状态分类系统，使用卷积神经网络(CNN)结合注意力机制，实现对植物叶片健康状态的自动识别和分类。项目包含完整的模型训练、消融实验和性能对比功能，旨在提供一个高效、准确的叶片健康状态检测解决方案。

## 核心技术

### 1. 模型架构

本项目实现了一个优化的多阶段CNN模型(`OptimizedMultiStageCNN`)，采用了分层设计理念，从浅到深逐步提取特征。模型架构详细如下：

#### 1.1 核心组件

- **深度可分离卷积(DSConv)**：
  - 分为深度卷积和逐点卷积两部分
  - 深度卷积：每个输入通道独立进行卷积操作
  - 逐点卷积：1×1卷积融合不同通道的信息
  - 优势：大幅减少参数量和计算量，提高模型效率

- **注意力机制**：
  - **CBAM (Convolutional Block Attention Module)**：
    - 通道注意力：通过全局平均池化学习通道间的重要性权重
    - 空间注意力：融合通道的最大值和平均值，生成空间重要性权重图
    - 应用位置：主要在模型浅层，用于过滤无效背景像素
  - **CoordAtt (Coordinate Attention)**：
    - 引入位置信息，通过水平和垂直池化捕获空间关系
    - 分别生成水平和垂直方向的注意力图
    - 应用位置：主要在模型深层，用于锁定目标的几何结构位置

#### 1.2 网络结构

```
输入 (224×224×3)
  ↓
Stage 1: 浅层特征提取
  - 3×3 卷积 (3→32)
  - 批归一化
  - ReLU激活
  - CBAM注意力模块
  ↓
Stage 2: 特征降维与增强 (输出: 112×112×64)
  - DSConv (32→64, stride=2)
  - CBAM注意力模块
  ↓
Stage 3: 深层特征提取 (输出: 56×56×128)
  - DSConv (64→128, stride=2)
  - CoordAtt注意力模块
  ↓
Stage 4: 语义特征提取 (输出: 28×28×256)
  - DSConv (128→256, stride=2)
  - CoordAtt注意力模块
  ↓
全局平均池化 (28×28×256 → 1×1×256)
  ↓
全连接分类器
  - 线性层 (256→128)
  - ReLU激活
  - Dropout (0.4)
  - 线性层 (128→4) [分类输出]
```

#### 1.3 设计理念

- **多阶段特征提取**：通过四个阶段逐步提取从低级到高级的特征
- **注意力机制分层应用**：浅层使用CBAM过滤背景，深层使用CoordAtt精确定位目标
- **轻量级设计**：使用深度可分离卷积减少参数量，适合在资源受限设备上部署
- **全局平均池化**：有效减少参数量，提高模型泛化能力
- **Dropout正则化**：防止过拟合，提高模型鲁棒性

### 2. 训练策略

- **数据增强**：随机水平翻转、随机旋转等
- **优化器**：AdamW优化器，带有权重衰减
- **学习率调度**：余弦退火学习率，帮助模型跳出局部最优
- **混合精度训练**：使用AMP(Automatic Mixed Precision)加速训练
- **批处理优化**：使用pin_memory和prefetch_factor加速数据加载

### 3. 实验功能

- **消融实验**：测试不同组件（DSConv、CBAM、CoordAtt）对模型性能的影响
- **模型对比**：与ResNet-18、MobileNet-V2、ShuffleNet-V2等经典模型进行对比
- **性能评估**：评估模型的准确率、参数量和推理速度

## 使用方法

### 1. 数据准备

将数据集按照以下结构组织：

```
datasets/
├── train/
│   └── 健康叶片/  # 健康叶片图像
└── test/
    └── 健康叶片/  # 健康叶片图像
```

### 2. 模型训练

运行`train.py`脚本训练模型：

```bash
python train.py
```

训练过程中会显示实时训练进度和损失值，训练完成后会保存模型到`models/`目录，并输出最终准确率和模型参数量。

### 3. 消融实验

运行`ablation_experiment.py`脚本进行消融实验：

```bash
python ablation_experiment.py
```

实验结果会保存在`ablation_results/`目录，包括：
- 消融实验报告CSV文件
- 学习曲线可视化图像
- 性能对比柱状图

### 4. 模型对比

运行`comparison_experiment.py`脚本与其他模型进行对比：

```bash
python comparison_experiment.py
```

对比结果会保存为`comparison_results.csv`文件，并生成性能对比散点图。
